NOVA COMPLETE BUILD
===================

Included:
- Smooth index-finger vision control using MediaPipe VIDEO mode.
- Accessibility gesture engine with queued low-latency movement.
- Natural-language command layer and Android global actions.
- Optional OpenAI-compatible AI endpoint with action planning.
- Local conversation memory and a simple local preference memory command.
- Web research/search snippets with browser fallback.
- Screen text reading through Android AccessibilityNodeInfo.
- Optional notification listener bridge.
- Voice input and text-to-speech.
- Optional user-started hands-free microphone foreground service.
- Futuristic NOVA control center UI.
- Accessibility and notification-access shortcuts.

AI configuration:
Open NOVA -> AI CORE -> enter an OpenAI-compatible chat-completions endpoint,
model, and API key if needed -> SAVE AI CORE.
No API key is embedded in this project.

Required Android setup after install:
1. Enable NOVA in Accessibility settings.
2. Grant Camera and Microphone permissions when requested.
3. Optionally enable NOVA Notification Access for notification features.
4. Configure AI CORE if natural-language reasoning is desired.

Safety/design:
NOVA uses official Android APIs and does not bypass device security or protected permissions.
