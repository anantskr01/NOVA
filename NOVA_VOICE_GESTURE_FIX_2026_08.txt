NOVA voice + gesture stabilization update

Voice:
- Added the missing Android imports required by NovaVoiceService.
- Added explicit RECORD_AUDIO permission checks.
- Added clearer foreground notification states and SpeechRecognizer availability logging.
- Added a timeout fallback after onEndOfSpeech for providers that fail to return a result.
- Added session guards to prevent duplicate restart loops.
- Kept the Android SpeechRecognizer best-effort model; this is not a hardware hotword DSP.

Gesture:
- Added a direction lock to CameraGestureService.
- When the finger moves in one direction, opposite movement is treated as return-to-center motion.
- Opposite movement is ignored until the finger is still for 300 ms.
- After the brief still period, the engine re-arms for a new direction.
- This prevents: right -> right action -> finger returns left -> accidental left action.

This archive was source-patched. Build on the target Windows/Android environment before installing.
