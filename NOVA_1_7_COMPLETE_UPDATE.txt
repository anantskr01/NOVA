NOVA 1–7 INTEGRATION UPDATE
============================

Completed in this pass:

1. Agent 2.0
- Added bounded OBSERVE -> ACT -> VERIFY flow.
- Added action allow-list.
- Added bounded retry and verification wait.
- Added safe-stop and recovery status reporting.
- Added wait action support.

2. UI intelligence
- Accessibility text matching now scores exact text, content descriptions,
  clickability, enabled state, focusability and visibility.
- Clicks the best visible target instead of the first matching node.
- UI snapshots now expose enabled/editable metadata.

3. Voice reliability
- Preserved the existing segmented microphone architecture, clap wake flow,
  recognizer restart path and background foreground-service model.
- MainActivity already maps voice states into the NOVA HUD.

4. Gesture reliability
- Preserved queued finger deltas and accessibility gesture serialization.
- Added a short retry when Android rejects a gesture dispatch.

5. NOVA HUD
- Existing HUD state integration is retained and now receives richer agent
  statuses such as THINKING, ACTIVE, ERROR and ONLINE from MainActivity.

6. Lifecycle / reliability
- Accessibility service clears queued motion and singleton state on destroy.
- MainActivity destroys SpeechRecognizer and NOVA assistant resources.
- Agent execution is bounded to 8 steps and 1 retry.

7. AI layer
- Local AI client now accepts a host, /api or /api/chat endpoint.
- Added 3 bounded connection attempts with backoff.
- Increased local-model read timeout to 90 seconds for slower tablet/LAN setups.
- Supports native Ollama, OpenAI-compatible chat, and direct response formats.

Important:
- The AI server must be reachable from the tablet over the LAN.
- This repository change cannot perform a physical Android build/install or
  verify device permissions from GitHub; run the build/install on the laptop.

Suggested validation:
  .\gradlew.bat assembleDebug
  .\gradlew.bat installDebug
  adb logcat -c
  adb logcat | Select-String "NovaAssistant|NovaAgentPlanner|NovaAI|NovaAccessibility|NovaVoice"
