NOVA 2.0 FINAL POLISH
======================

Integrated from the previous AirControl_NOVA_5_6_7_8 project.

Added / polished:
3. Voice experience
   - Hands-free foreground microphone service
   - Hey NOVA wake gate using Android SpeechRecognizer
   - Active follow-up listening window
   - Duplicate phrase suppression
   - Stop hands-free control

4. Central Action Engine
   - Home/back/recents/notifications/quick settings
   - Scroll/swipe actions
   - URL/package/app launching
   - Settings
   - Accessibility-aware action failures
   - Visible-text click support through AccessibilityService

5. Dynamic app control
   - Discovers launcher apps at runtime
   - Opens apps by human-readable name
   - No hard-coded app list required

6. Notification intelligence
   - Local notification snapshot
   - App labels included when available
   - Short local history
   - Android notification-access permission remains user-controlled

7. Skills architecture
   - Existing built-in NovaSkillRegistry retained
   - NovaSkill extension interface added
   - External skills can register independently

8. NOVA HUD
   - Animated, lightweight native HUD
   - Online/listening/thinking/active/error states
   - No external graphics dependency
   - Futuristic dark control surface

9. Performance
   - Finger tracking smoothing tuned for responsiveness
   - Camera frame throttling
   - Lower gesture interval
   - Bounded accessibility movement queue
   - Existing MediaPipe video tracking retained

10. Security / privacy
   - API key moved to Android Keystore-backed AES/GCM storage
   - No API key bundled in source or APK
   - Android permissions remain explicit
   - No security or accessibility bypasses

Build note:
The project was structurally checked for Java brace balance and XML parsing.
A Gradle build could not be executed in this environment because the required
Gradle 8.7 distribution is not locally cached and this environment has no
external network access. Run the normal Gradle build on the development PC.

Recommended first PC commands:
    .\gradlew.bat clean
    .\gradlew.bat assembleDebug

APK output:
    app\build\outputs\apk\debug\app-debug.apk
