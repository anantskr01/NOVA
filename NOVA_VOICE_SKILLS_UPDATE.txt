NOVA VOICE + SKILLS UPDATE

Added:
- Lightweight Hey NOVA wake-word gate for hands-free mode.
- 12-second conversational window after wake phrase for follow-up voice requests.
- Improved natural-language AI system prompt and conversation context.
- Built-in skill registry with battery/device info, calculator, timers, reminders, calendar, maps/navigation, files/downloads, Wi-Fi/Bluetooth settings.
- Local reminder receiver using Android AlarmManager + notifications.
- Android 13+ POST_NOTIFICATIONS permission request.
- Hands-free UI status now tells the user to say Hey NOVA.

Android limitations:
- Android's speech recognizer is used as the wake detector; this is not a dedicated on-device keyword engine.
- Continuous microphone use requires the foreground microphone service and user permission.
- Notification delivery depends on Android notification permission.
