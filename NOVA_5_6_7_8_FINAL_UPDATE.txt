NOVA FEATURES 5-8 UPDATE

5. Wake-word experience
- Hands-free voice mode now listens for a lightweight "Hey NOVA" / "NOVA" activation phrase.
- After activation, NOVA accepts follow-up voice requests for a short conversational window.
- Voice service can be stopped by stopping the foreground service from Android.

6. Better voice conversation
- AI system prompt now supports ordinary conversation, follow-up questions, clarification, and concise spoken answers.
- Recent conversation history is included in AI requests.
- AI action plans remain restricted to NOVA's explicit tool set.

7. Proactive assistant foundations
- Local reminders and timers use Android AlarmManager and a NOVA notification receiver.
- Android 13+ notification permission is requested.
- Scheduled reminders survive the app UI being closed; delivery depends on Android's normal alarm/notification policies.
- Existing notification-access bridge can provide recent notification context when the user enables it.

8. Expanded skill system
- Calculator
- Timers
- Reminders
- Calendar
- Maps / navigation
- Files / downloads
- Wi-Fi / Bluetooth settings
- Battery level
- Device information
- Existing browser / YouTube / web search / Android navigation / accessibility / screen-reading skills remain available.

Important platform limits
- Wake-word detection uses Android SpeechRecognizer as a lightweight gate; it is not a dedicated offline keyword model.
- Continuous microphone use requires the microphone foreground-service permission and user permission.
- Android controls protected APIs and may restrict background behavior, notifications, exact alarms, and some app UI automation.
